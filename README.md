# Universal Android Debloater TUI

## Introduction

Universal Android Debloater TUI is a lightweight terminal-based tool for removing unwanted Android system apps using ADB. It provides a fast, keyboard-driven interface designed for simplicity and efficiency, making it ideal for users who prefer working in the terminal over heavy GUI tools.

## Features

* ADB device detection and connection status
* Interactive terminal UI with smooth navigation
* View all installed packages on the device
* Select and manage apps using keyboard controls
* Batch uninstall for quick debloating
* Minimal, clean interface (Catppuccin-inspired)
* Lightweight and portable (no unnecessary dependencies)
